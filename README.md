# OPD Management System

## 📌 About Project

A backend-based OPD (Outpatient Department) Management System developed using Java, Spring Boot, Hibernate, and MySQL.

This project helps manage:

- Patients
- Doctors
- Appointments
- OPD Records

The system is designed using RESTful APIs and follows a clean backend architecture

---

## 🛠️ Tech Stack

- Java
- Spring Boot
- Hibernate ORM
- Spring Data JPA
- MySQL
- Maven
